## The Empty Function Need Not Be Written

In a script, a set-valued functor may now leave out the action of an arrow whose source has no element: there is one function from the empty set, and kategoria takes it. Before, such a functor was refused as not given on every arrow, so that a table with no rows could not be written at all.

An arrow into an empty set from a set with an element is still refused, as it must be.

This lets a record of the infrastructure's history domain be written as a functor on its schema whatever tables it leaves empty.
